# Levex Auto App

Welcome to Levex Auto, your one-stop solution for seamless car importation and dealership integration. This Flutter-based cross-platform app revolutionizes the car buying experience with real-time tracking, taxation calculations, and a user-friendly interface.

## Technologies Used
- **Flutter**: Utilized for cross-platform development, ensuring compatibility with both Android and iOS devices.
- **Firebase**: Employs Firebase for secure user authentication and real-time database management.
- **Google Maps API**: Integrates Google Maps API to provide location-based services, enhancing user experience.
- **AI Technology**: Implements AI technology for personalized recommendations and optimized search results.
- **Push Notifications**: Utilizes push notifications to keep users updated on order tracking and bid status.

## Key Features
- **Real-Time Tracking**: Track the status of your car order from purchase to delivery in real-time.
- **Taxation Calculations**: Accurately calculate import duties, VAT, and platform fees for transparent pricing.
- **Bidding System**: Participate in auctions for exclusive car models and secure the best deals.
- **Dealer Integration**: Seamlessly integrate dealership profiles and inventory for easy access to luxury car listings.
- **Personalized Recommendations**: Receive tailored recommendations based on location, preferences, and browsing history.
- **User-Friendly Interface**: Enjoy a sleek and intuitive interface designed for optimal user experience.

## Setup Instructions
1. Clone the repository to your local machine.
2. Ensure you have Flutter installed. If not, follow the instructions [here](https://flutter.dev/docs/get-started/install).
3. Run `flutter pub get` in the project directory to install dependencies.
4. Connect your device or start an emulator.
5. Run `flutter run` to launch the app on your device or emulator.
